# Kirchhoff

Kirchhoff turns weeks of scarce senior-engineer work into one reviewed, signed design session. Gemini agents read the tender, design power and cooling for an AI data hall, and hand off to procurement and sales; a deterministic checker proves every number; the engineer decides and signs. *AI designs. Physics checks. An engineer signs.*

Run locally: `make dev-api` and `make dev-web`; tests: `make test`.
