# Kirchhoff P4 — Enterprise Sandbox, Demo World, Infra, Golden Capture and E2E (WS4) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Everything WS4 owns for the 17 Oct submission: the ERP/CRM sandbox as its own Cloud Run service with the Python client WS2 calls and the `/api/enterprise/*` proxy WS3 reads, the deterministic demo world (world, integrations snapshot, project bundles, enterprise seed, documents), the golden capture that turns a recorded Hall B run into the signed static Hall A, a correct and least-privilege production deployment (image, service account, cache headers, CORS, App Check, uptime checks, budget), and the Playwright end-to-end suite.

**Architecture:** One container image (built once by Cloud Build from a staged context that adds `scenarios/` and the static seed bundles) runs as two Cloud Run services under a dedicated runtime service account: `kirchhoff-api` (public, behind Firebase Hosting) and `kirchhoff-enterprise` (IAM-only, same image, `uvicorn kirchhoff.enterprise.app:create_enterprise_app`). The sandbox keeps seed data in Firestore `seed/**` and each visitor's PRs/CRM overlays in `sandbox_visitors/{uid}/**`; the API reaches it with a Google ID token through `make_enterprise_client()`. The demo world is generated by pure, seeded Python (`kirchhoff.enterprise.world`) from an authored `scenarios/demo_world/world.yaml`, the engine facade and (after Thursday) the captured Hall B run, and is written to `apps/web/public/demo/**` (Hosting, static-first) and `scenarios/demo_world/out/**` (image + Firestore seed).

**Tech Stack:** Python 3.12, FastAPI 0.141, pydantic 2.14, httpx, google-auth, google-cloud-firestore, google-cloud-storage, reportlab 5.0.1, pyyaml, pytest; bash + gcloud 551 (Cloud Run, Cloud Build, Artifact Registry, IAM, Monitoring, Billing Budgets, Secret Manager), Firebase Hosting (firebase-tools), Firebase App Check REST API v1; Node 26 + `@playwright/test` 1.64.0.

```python
from kirchhoff.contracts import PRLine

def test_seed_loads_and_lists_sorted(sandbox, small_seed):
    assert [m.id for m in sandbox.list_materials()] == ["BW-1600", "TX-2500", "TX-3150"]
    assert [p.id for p in sandbox.list_prs(None)] == ["PR-2026-0142"]

    smaller = small_seed.model_copy(update={"materials": small_seed.materials[:1]})
    assert sandbox.load_seed(smaller) == {"materials": 1, "prs": 1, "opportunities": 2}
```

```python
"""ERP/CRM sandbox (spec §9.5, §13.3) over the Store protocol. Seed data is read-only; each visitor's PRs and CRM
stage overlays live under sandbox_visitors/{uid} (ruling W1). Stock is never decremented. Sandbox (simulated)."""
import hashlib
import time
from typing import Callable

from kirchhoff.contracts import CrmOverlay, Material, Opportunity, PRLine, PurchaseRequisition
from kirchhoff.store import Store
from kirchhoff.store.validate import firestore_safe_problems

from .model import EnterpriseSeed, seed_hash

MATERIALS = "seed/erp/materials"
SEED_PRS = "seed/erp/prs"
OPPORTUNITIES = "seed/crm/opportunities"
SEED_META = "seed/meta"
COUNTERS = "sandbox_meta/counters"
FIRST_VISITOR_PR = 301
PR_STATUSES = ("draft", "submitted", "blocked")
STAGES = ("Qualification", "Proposal", "Negotiation", "Design in progress", "Design approved", "Closed won",
          "Closed lost")


class NotFound(KeyError):
    """Unknown PR or opportunity (HTTP 404)."""


def visitor_path(uid: str) -> str:
    if not uid or "/" in uid:
        raise ValueError("uid must be a non-empty string without '/'")
    return f"sandbox_visitors/{uid}"


def key_id(idempotency_key: str) -> str:
    """Idempotency keys contain ':' and vendor names; hash them into a valid document id."""
    return hashlib.sha256(idempotency_key.encode("utf-8")).hexdigest()[:40]


def _doc_id(value: str) -> str:
    if not value or "/" in value:
        raise NotFound(value)
    return value


class Sandbox:
    def __init__(self, store: Store, clock: Callable[[], float] = time.time) -> None:
        self.store = store
        self.clock = clock

    # ---- seed -------------------------------------------------------------------------------------------
    def load_seed(self, seed: EnterpriseSeed) -> dict[str, int]:
        items = [(f"{MATERIALS}/{m.id}", m.model_dump(mode="json")) for m in seed.materials]
        items += [(f"{SEED_PRS}/{p.id}", p.model_dump(mode="json")) for p in seed.prs]
        items += [(f"{OPPORTUNITIES}/{o.id}", o.model_dump(mode="json")) for o in seed.opportunities]
        problems = [f"{path}: {p}" for path, doc in items for p in firestore_safe_problems(doc)]
        if problems:
            raise ValueError("seed is not Firestore-safe: " + "; ".join(problems[:5]))
        self.store.delete_tree("seed/erp")
        self.store.delete_tree("seed/crm")
        self.store.batch_set(items)
        counts = {"materials": len(seed.materials), "prs": len(seed.prs), "opportunities": len(seed.opportunities)}
        self.store.set_doc(SEED_META, {**counts, "hash": seed_hash(seed), "accounts": list(seed.accounts),
                                       "notice": seed.notice, "label": seed.label})
        return counts

    def meta(self) -> dict:
        return self.store.get_doc(SEED_META) or {}

    # ---- ERP ----------------------------------------------------------------------------------------------
    def list_materials(self) -> list[Material]:
        return sorted((Material.model_validate(d) for d in self.store.list_docs(MATERIALS)), key=lambda m: m.id)

    def list_prs(self, uid: str | None) -> list[PurchaseRequisition]:
        prs = [PurchaseRequisition.model_validate(d) for d in self.store.list_docs(SEED_PRS)]
        if uid:
            prs += [PurchaseRequisition.model_validate(d) for d in self.store.list_docs(f"{visitor_path(uid)}/prs")]
        return sorted(prs, key=lambda p: (-p.created_at, p.id))

    def create_pr(self, uid: str, project_id: str, revision: str, lines: list[PRLine],
                  idempotency_key: str) -> PurchaseRequisition:
        base = visitor_path(uid)
        if not idempotency_key:
            raise ValueError("idempotency_key is required")
        if not lines:
            raise ValueError("a purchase requisition needs at least one line")
        key_doc = f"{base}/keys/{key_id(idempotency_key)}"
        out: dict = {}

        def fn(snap: dict) -> list:
            out.clear()  # Firestore may retry the transaction function
            known = snap.get(key_doc)
            if known is not None:
                out["existing"] = known["pr_id"]
                return []
            n = int((snap.get(COUNTERS) or {}).get("next_pr", FIRST_VISITOR_PR))
            pr = PurchaseRequisition(id=f"PR-2026-{n:04d}", project_id=project_id, revision=revision,
                                     lines=list(lines), status="submitted", created_at=self.clock())
            out["pr"] = pr
            return [(f"{base}/prs/{pr.id}", pr.model_dump(mode="json")),
                    (key_doc, {"pr_id": pr.id, "key": idempotency_key}),
                    (COUNTERS, {"next_pr": n + 1})]

        self.store.transact([key_doc, COUNTERS], fn)
        if "existing" in out:
            doc = self.store.get_doc(f"{base}/prs/{out['existing']}")
            if doc is None:
                raise NotFound(out["existing"])
            return PurchaseRequisition.model_validate(doc)
        return out["pr"]

    def set_pr_status(self, uid: str, pr_id: str, status: str) -> None:
        if status not in PR_STATUSES:
            raise ValueError(f"status must be one of {PR_STATUSES}")
        path = f"{visitor_path(uid)}/prs/{_doc_id(pr_id)}"

        def fn(snap: dict) -> list:
            doc = snap.get(path)
            if doc is None:
                raise NotFound(pr_id)
            return [(path, {**doc, "status": status})]

        self.store.transact([path], fn)

    # ---- CRM ----------------------------------------------------------------------------------------------
    def list_opportunities(self, uid: str | None) -> list[Opportunity]:
        opps = sorted((Opportunity.model_validate(d) for d in self.store.list_docs(OPPORTUNITIES)), key=lambda o: o.id)
        if not uid:
            return opps
        stages = {d["opportunity_id"]: d["stage"] for d in self.store.list_docs(f"{visitor_path(uid)}/crm")}
        return [o.model_copy(update={"stage": stages[o.id]}) if o.id in stages else o for o in opps]

    def set_opportunity_stage(self, uid: str, opportunity_id: str, stage: str) -> CrmOverlay:
        base = visitor_path(uid)
        if stage not in STAGES:
            raise ValueError(f"stage must be one of {STAGES}")
        if self.store.get_doc(f"{OPPORTUNITIES}/{_doc_id(opportunity_id)}") is None:
            raise NotFound(opportunity_id)
        ov = CrmOverlay(opportunity_id=opportunity_id, stage=stage, updated_at=self.clock())
        self.store.set_doc(f"{base}/crm/{opportunity_id}", ov.model_dump(mode="json"))
        return ov

    def reset_visitor(self, uid: str) -> int:
        return self.store.delete_tree(visitor_path(uid))
```

```python
Cloud Run IAM admits only the runtime service account (ruling W2); requests carry the visitor uid.
Sandbox (simulated): every record is fictional."""
import os
from typing import Callable

from fastapi import FastAPI, Query
from fastapi.responses import JSONResponse
from pydantic import BaseModel

from kirchhoff.contracts import PRLine

from .model import SANDBOX_LABEL
from .sandbox import NotFound, Sandbox


class CreatePr(BaseModel):
    uid: str
    project_id: str
    revision: str
    lines: list[PRLine]
    idempotency_key: str


class SetStatus(BaseModel):
    uid: str
    status: str


class SetStage(BaseModel):
    uid: str
    stage: str


def _guard(fn: Callable[[], object]):
    try:
        return fn()
    except NotFound as exc:
        return JSONResponse(status_code=404, content={"detail": f"not_found: {exc.args[0] if exc.args else ''}"})
    except ValueError as exc:
        return JSONResponse(status_code=422, content={"detail": str(exc)})


def create_enterprise_app(sandbox: Sandbox | None = None) -> FastAPI:
    if sandbox is None:
        from kirchhoff.store.firestore import FirestoreStore
        sandbox = Sandbox(FirestoreStore())
    app = FastAPI(title="Kirchhoff enterprise sandbox (simulated)")

    @app.get("/health")
    def health() -> dict:
        meta = sandbox.meta()
        return {"ok": True, "service": "kirchhoff-enterprise", "label": SANDBOX_LABEL,
                "version": os.environ.get("K_REVISION", "dev"), "seed_hash": meta.get("hash"),
                "materials": meta.get("materials", 0)}
```

```python
class GoogleIdTokens:
    """Google-signed ID tokens for Cloud Run service-to-service calls (metadata server on Cloud Run), cached."""

    def __init__(self, audience: str, ttl_s: float = 3000.0) -> None:
        self.audience, self.ttl_s = audience, ttl_s
        self._token: str | None = None
        self._at = 0.0
        self._lock = threading.Lock()

    def __call__(self) -> str:
        with self._lock:
            if self._token is None or time.monotonic() - self._at > self.ttl_s:
                import google.auth.transport.requests
                import google.oauth2.id_token

                self._token = google.oauth2.id_token.fetch_id_token(google.auth.transport.requests.Request(),
                                                                    self.audience)
                self._at = time.monotonic()
            return self._token


class HttpEnterpriseClient:
    """kirchhoff-enterprise over HTTPS. 3 s per attempt and one retry keep request-path calls under 10 s."""

    def __init__(self, base_url: str, token: Callable[[], str] | None = None, timeout_s: float = 3.0,
                 retries: int = 1, http: httpx.Client | None = None) -> None:
        self.base_url = base_url.rstrip("/")
        self._token = token or GoogleIdTokens(self.base_url)
        self._timeout = httpx.Timeout(timeout_s, connect=min(1.5, timeout_s))
        self._retries = retries
        self._http = http
        self._lock = threading.Lock()

    def _client(self) -> httpx.Client:
        with self._lock:
            if self._http is None:
                self._http = httpx.Client(base_url=self.base_url, timeout=self._timeout)
            return self._http

    def _call(self, method: str, path: str, *, params: dict | None = None, body: dict | None = None) -> Any:
        last: object = None
        for _ in range(1 + self._retries):
            try:
                token = self._token()
            except Exception as exc:
                raise EnterpriseUnavailable(f"no ID token for {self.base_url}: {type(exc).__name__}") from exc
            try:
                r = self._client().request(method, path, params=params, json=body,
                                           headers={"Authorization": f"Bearer {token}"})
            except httpx.HTTPError as exc:  # connect/read timeouts, refused connections
                last = exc
                continue
            if r.status_code == 404:
                raise NotFound(r.json().get("detail", path))
            if r.status_code == 422:
                raise ValueError(str(r.json().get("detail", "invalid request")))
            if r.status_code >= 500:
                last = f"HTTP {r.status_code}"
                continue
            if r.status_code >= 400:
                raise EnterpriseUnavailable(f"{method} {path} -> HTTP {r.status_code}")
            return r.json()
        raise EnterpriseUnavailable(f"{method} {path} failed after {1 + self._retries} attempts: {last!r}")

    def list_materials(self) -> list[Material]:
        return [Material.model_validate(x) for x in self._call("GET", "/erp/materials")]

    def list_prs(self, uid: str | None) -> list[PurchaseRequisition]:
        data = self._call("GET", "/erp/prs", params={"uid": uid} if uid else None)
        return [PurchaseRequisition.model_validate(x) for x in data]

    def create_pr(self, uid, project_id, revision, lines, idempotency_key) -> PurchaseRequisition:
        body = {"uid": uid, "project_id": project_id, "revision": revision,
                "lines": [PRLine.model_validate(x).model_dump(mode="json") for x in lines],
                "idempotency_key": idempotency_key}
        return PurchaseRequisition.model_validate(self._call("POST", "/erp/prs", body=body))

    def set_pr_status(self, uid, pr_id, status) -> None:
        self._call("POST", f"/erp/prs/{quote(pr_id, safe='')}/status", body={"uid": uid, "status": status})

    def list_opportunities(self, uid: str | None) -> list[Opportunity]:
        data = self._call("GET", "/crm/opportunities", params={"uid": uid} if uid else None)
        return [Opportunity.model_validate(x) for x in data]

    def set_opportunity_stage(self, uid, opportunity_id, stage) -> CrmOverlay:
        data = self._call("POST", f"/crm/opportunities/{quote(opportunity_id, safe='')}/stage",
                          body={"uid": uid, "stage": stage})
        return CrmOverlay.model_validate(data)

    def reset_visitor(self, uid) -> None:
        self._call("DELETE", f"/visitors/{quote(uid, safe='')}")

    def health(self) -> dict:
        return self._call("GET", "/health")


class _LazyFirestore:
    """Creates the Firestore client on first use (no network at construction)."""

    def __init__(self) -> None:
        self._store = None
        self._lock = threading.Lock()

    def __getattr__(self, name: str):
        if name.startswith("_"):
            raise AttributeError(name)
        with self._lock:
            if self._store is None:
                from kirchhoff.store.firestore import FirestoreStore
                self._store = FirestoreStore()
        return getattr(self._store, name)

def default_seed(env: Mapping[str, str]) -> EnterpriseSeed:
    path = env.get("KIRCHHOFF_ENTERPRISE_SEED") or str(enterprise_seed_path())
    try:
        return load_enterprise_seed(path)

def _memory_client(env: Mapping[str, str]) -> LocalEnterpriseClient:
    sandbox = Sandbox(MemoryStore())
    try:
        sandbox.load_seed(default_seed(env))
    except Exception as exc:  # a broken seed must never stop the API from starting
        log.warning("enterprise seed rejected (%s); starting with an empty ERP", type(exc).__name__)
        sandbox.load_seed(EnterpriseSeed(materials=[], opportunities=list(FALLBACK_OPPORTUNITIES)))

def make_enterprise_client(env: Mapping[str, str] | None = None):
    """Ruling W4: HTTP when KIRCHHOFF_ENTERPRISE_URL is set, else an in-process sandbox (memory by default,
    KIRCHHOFF_ENTERPRISE=firestore for the real seed). One instance per mode per process."""
    env = os.environ if env is None else env
    url = (env.get("KIRCHHOFF_ENTERPRISE_URL") or "").strip()
    mode = "http" if url else (env.get("KIRCHHOFF_ENTERPRISE") or "memory")
    key = (mode, url or env.get("KIRCHHOFF_ENTERPRISE_SEED", ""))
    with _CLIENTS_LOCK:
        if key not in _CLIENTS:
            if mode == "http":
                _CLIENTS[key] = HttpEnterpriseClient(url)
            elif mode == "firestore":
                _CLIENTS[key] = LocalEnterpriseClient(Sandbox(_LazyFirestore()))
            else:
                _CLIENTS[key] = _memory_client(env)
        return _CLIENTS[key]


def reset_client_cache() -> None:
    with _CLIENTS_LOCK:
        _CLIENTS.clear()
```

```python
"""/api/enterprise/* (spec §7; interfaces HTTP table): the UI never calls the sandbox directly. Read-only views for
the signed-in visitor; the sandbox is the source of truth (ruling W5). P2's create_app mounts this router."""
import logging
from typing import Callable

from fastapi import APIRouter, Depends
from fastapi.responses import JSONResponse

log = logging.getLogger("kirchhoff")


def make_router(store, current_uid, client=None) -> APIRouter:
    """`store` keeps P2's create_app signature; `client` is injectable for tests (default: the shared client)."""
    router = APIRouter()
    holder = {"client": client}

    def enterprise():
        if holder["client"] is None:
            from kirchhoff.enterprise.client import make_enterprise_client
            holder["client"] = make_enterprise_client()
        return holder["client"]

    def respond(fn: Callable[[], list]):
        try:
            return fn()
        except Exception as exc:  # the UI falls back to /demo/integrations.json
            log.warning("enterprise proxy failed: %s", type(exc).__name__)
            return JSONResponse(status_code=502, content={"detail": "enterprise_unavailable"})

    @router.get("/api/enterprise/erp/materials")
    def materials(uid: str = Depends(current_uid)):
        return respond(lambda: [m.model_dump(mode="json") for m in enterprise().list_materials()])

    @router.get("/api/enterprise/erp/prs")
    def prs(uid: str = Depends(current_uid)):
        return respond(lambda: [p.model_dump(mode="json") for p in enterprise().list_prs(uid)])

    @router.get("/api/enterprise/crm/opportunities")
    def opportunities(uid: str = Depends(current_uid)):
        return respond(lambda: [o.model_dump(mode="json") for o in enterprise().list_opportunities(uid)])

    return router
```

```python
"""ERP and CRM seed for the demo world (spec §9.5, §13.3): Hall A materials verbatim + 40 authored extras, 5 accounts,
9 opportunities and historical PRs. Deterministic for a given world.yaml (ruling W7). Sandbox (simulated)."""
from pathlib import Path
from typing import Iterable

import yaml

from kirchhoff.contracts import Material, Opportunity, PRLine, PurchaseRequisition

from ..model import EnterpriseSeed
from .config import HISTORICAL_PR_BASE, WorldConfig, rng_for


class MaterialsErp:
    """The engine facade's ErpView (get/search) over a materials list."""

    def __init__(self, materials: list[Material]) -> None:
        self._by_id = {m.id: m for m in materials}

    def get(self, material_id: str) -> Material:
        return self._by_id[material_id]

    def search(self, category: str) -> list[Material]:
        return sorted((m for m in self._by_id.values() if m.category == category), key=lambda m: m.id)


def hall_a_materials(scenarios_root: Path) -> list[Material]:
    data = yaml.safe_load((Path(scenarios_root) / "hall_a" / "erp_seed.yaml").read_text(encoding="utf-8"))
    return [Material.model_validate(m) for m in data["materials"]]


def build_materials(cfg: WorldConfig, hall_a: list[Material]) -> list[Material]:
    rng = rng_for(cfg, "materials")
    extras = [Material(id=x.id, category=x.category, description=x.description, rating=x.rating, unit=x.unit,
                       voltage=x.voltage, stock=rng.randint(*x.stock), lead_time_weeks=x.lead_time_weeks,
                       unit_price=x.unit_price, vendor=x.vendor) for x in cfg.extra_materials]
    ids = [m.id for m in hall_a] + [m.id for m in extras]
    dupes = sorted({i for i in ids if ids.count(i) > 1})
    if dupes:
        raise ValueError(f"duplicate material ids: {dupes}")
    return sorted(hall_a + extras, key=lambda m: m.id)


def build_opportunities(cfg: WorldConfig) -> list[Opportunity]:
    unknown = sorted({o.account for o in cfg.opportunities} - set(cfg.accounts))
    if unknown:
        raise ValueError(f"opportunities reference unknown accounts: {unknown}")
    rng = rng_for(cfg, "crm")
    opps = [Opportunity(id=o.id, account=o.account, name=o.name, stage=o.stage,
                        value=float(round(rng.uniform(*o.value), -4)), next_step=o.next_step)
            for o in cfg.opportunities]
    return sorted(opps, key=lambda o: o.id)


def build_historical_prs(cfg: WorldConfig, materials: list[Material]) -> list[PurchaseRequisition]:
    rng = rng_for(cfg, "prs")
    by_id = {m.id: m for m in materials}
    out = []
    for i, h in enumerate(sorted(cfg.historical_prs, key=lambda h: (-h.days_ago, h.project_id))):
        lines = []
        for line in h.lines:
            m = by_id[line.material_id]
            lines.append(PRLine(material_id=m.id, description=m.description, qty=rng.randint(*line.qty),
                                unit_price=m.unit_price, lead_time_weeks=m.lead_time_weeks))
        out.append(PurchaseRequisition(id=f"PR-2026-{HISTORICAL_PR_BASE + i:04d}", project_id=h.project_id,
                                       revision=h.revision, lines=lines, status=h.status,
                                       created_at=cfg.ts(h.days_ago)))
    return out


def build_enterprise_seed(cfg: WorldConfig, materials: list[Material],
                          project_prs: Iterable[PurchaseRequisition] = ()) -> EnterpriseSeed:
    prs = build_historical_prs(cfg, materials) + list(project_prs)
    ids = [p.id for p in prs]
    if len(ids) != len(set(ids)):
        raise ValueError(f"duplicate PR ids: {sorted({i for i in ids if ids.count(i) > 1})}")
    known = {m.id for m in materials}
    missing = sorted({line.material_id for p in prs for line in p.lines} - known)
    if missing:
        raise ValueError(f"PR lines reference unknown materials: {missing}")
    return EnterpriseSeed(notice=cfg.notice, materials=materials, prs=sorted(prs, key=lambda p: p.id),
                          accounts=list(cfg.accounts), opportunities=build_opportunities(cfg))
```

```bash
#!/usr/bin/env bash
# Uptime checks on / and /api/health with email alerts (spec §11). Idempotent.
# Usage: ALERT_EMAIL=<team alert address> infra/monitoring_setup.sh      (the address is never committed)
set -euo pipefail
P=ordinal-mep
HOST=kirchhoff.web.app
: "${ALERT_EMAIL:?set ALERT_EMAIL to the team alert address}"

CHANNEL="$(gcloud beta monitoring channels list --project=$P --filter='displayName="Kirchhoff alerts"' \
  --format='value(name)' | head -1)"
if [ -z "$CHANNEL" ]; then
  CHANNEL="$(gcloud beta monitoring channels create --project=$P --type=email --display-name="Kirchhoff alerts" \
    --channel-labels=email_address="$ALERT_EMAIL" --format='value(name)')"
fi

check_id() {  # display name -> uptime check id, or "" when absent
  gcloud monitoring uptime list-configs --project=$P --filter="displayName=\"$1\"" --format='value(name)' \
    | head -1 | sed 's#.*/##'
}
ensure_check() {  # display name, path, content matcher
  if [ -z "$(check_id "$1")" ]; then
    gcloud monitoring uptime create "$1" --project=$P --resource-type=uptime-url \
      --resource-labels=host=$HOST,project_id=$P --protocol=https --port=443 --path="$2" \
      --period=5 --timeout=10 --matcher-type=contains-string --matcher-content="$3" >/dev/null
  fi
  check_id "$1"
}
WEB_ID="$(ensure_check kirchhoff-web / 'id="root"')"
API_ID="$(ensure_check kirchhoff-api-health /api/health '"ok":true')"

ensure_policy() {  # display name, uptime check id
  if [ -n "$(gcloud monitoring policies list --project=$P --filter="displayName=\"$1\"" --format='value(name)' | head -1)" ]; then
    return 0
  fi
  local f
  f="$(mktemp)"
  cat > "$f" <<JSON
{
  "displayName": "$1",
  "combiner": "OR",
  "conditions": [{
    "displayName": "$1: uptime check failing",
    "conditionThreshold": {
      "filter": "metric.type=\"monitoring.googleapis.com/uptime_check/check_passed\" AND metric.label.check_id=\"$2\" AND resource.type=\"uptime_url\"",
      "aggregations": [{"alignmentPeriod": "1200s", "perSeriesAligner": "ALIGN_NEXT_OLDER",
                        "crossSeriesReducer": "REDUCE_COUNT_FALSE", "groupByFields": ["resource.label.*"]}],
      "comparison": "COMPARISON_GT", "thresholdValue": 1, "duration": "300s", "trigger": {"count": 1}
    }
  }],
  "notificationChannels": ["$CHANNEL"]
}
JSON
  gcloud monitoring policies create --project=$P --policy-from-file="$f" >/dev/null
  rm -f "$f"
}
ensure_policy "Kirchhoff web down" "$WEB_ID"
ensure_policy "Kirchhoff API health down" "$API_ID"
echo "uptime checks: kirchhoff-web=$WEB_ID kirchhoff-api-health=$API_ID; alerts -> $CHANNEL"
```

```python
"""Turn engine result dicts (pydantic models, tuples, numpy scalars) into plain JSON values for static bundles."""
import math
from typing import Any

from pydantic import BaseModel


def jsonable(value: Any) -> Any:
    if isinstance(value, BaseModel):
        return jsonable(value.model_dump(mode="json"))
    if isinstance(value, dict):
        return {str(k): jsonable(v) for k, v in value.items() if not str(k).startswith("_")}
    if isinstance(value, (list, tuple)):
        return [jsonable(v) for v in value]
    if value is None or isinstance(value, (str, bool)):
        return value
    if isinstance(value, int):
        return int(value)
    if isinstance(value, float):
        return value if math.isfinite(value) else None
    if hasattr(value, "item"):  # numpy scalar
        return jsonable(value.item())
    return str(value)
```

```python
POWER_RULES = {"R01", "R02", "R03", "R04", "R04b", "R05", "R06", "R07", "R13"}
COOLING_RULES = {"R08", "R09", "R10", "R11", "R14"}

def choose_fix(finding: Finding, candidates: list) -> tuple[Any, str, str]:
    """P2 ruling R23, the same criteria the live agents state: Cooling takes the fewest changed pipe segments, then
    cost; Power takes the largest voltage-drop margin per dollar; everything else the cheapest candidate."""
    if finding.rule_id in COOLING_RULES:
        best = min(candidates, key=lambda c: (c.metrics.get("changed_pipes", float("inf")), c.cost_delta, c.id))
        return best, "fewest changed pipe segments, then cost", "cooling"
    if finding.rule_id in POWER_RULES:
        def margin(c) -> float:
            if "dv_pct" not in c.metrics or "dv_limit_pct" not in c.metrics:
                return float("-inf")
            return (c.metrics["dv_limit_pct"] - c.metrics["dv_pct"]) / max(c.cost_delta, 1.0)
        best = sorted(candidates, key=lambda c: (-margin(c), c.cost_delta, c.id))[0]
        return best, "largest voltage-drop margin per dollar", "power"
    return min(candidates, key=lambda c: (c.cost_delta, c.id)), "lowest cost", "procurement"


def pr_id_seq(base: int) -> Iterator[str]:
    return (f"PR-2026-{base + i:04d}" for i in itertools.count())


def prs_by_vendor(lines: list[PRLine], erp, *, project_id: str, revision: str, created_at: float,
                  pr_ids: Iterator[str]) -> list[PurchaseRequisition]:
    """One PR per ERP vendor, vendors in alphabetical order (the live P4 step does the same)."""
    groups: dict[str, list[PRLine]] = {}
    for line in lines:
        groups.setdefault(erp.get(line.material_id).vendor, []).append(line)
    return [PurchaseRequisition(id=next(pr_ids), project_id=project_id, revision=revision, lines=groups[v],
                                status="submitted", created_at=round(created_at + i, 3))
            for i, v in enumerate(sorted(groups))]


def chip_what_ifs(engine, scn, model, erp, ref: str, required: bool = False) -> list:

    if what_if is not None:
        return [what_if(scn, model, p, v, ref, erp) for p, v in CHIP_WHAT_IFS]
    if required:
        raise RuntimeError("engine.what_if is not available yet (WS1 P1 Task 15); chip what-ifs are required")

def _counts(findings: list[Finding]) -> dict[str, int]:
    return {s: sum(f.status == s for f in findings) for s in ("pass", "fail", "warn", "n/a")}


def _ledger(engine, swaps: list[dict]) -> list[LedgerEntry]:
    did = [LedgerEntry(kind="did", agent="procurement", text=f"{s['from']} replaced by {s['to']} (R15 lead time)")
           for s in swaps if s.get("to")]
    return did + [LedgerEntry(kind="not_checked", agent="checker", text=t) for t in engine.ledger_not_checked()]


def datahall_bundle(engine, scn, erp, *, project: Project, topology: str, signed_at: float, pr_ids: Iterator[str],
                    opportunity_id: str | None = None, what_ifs: bool = False) -> ProjectBundle:
    options = engine.annotate_options(scn, engine.power_options(scn, engine.place_racks(scn)), erp)
    option, model = next((o, m) for o, m in options if o.id == topology)
    model = engine.route(scn, model)
    revs: list[tuple[Any, list[Finding]]] = [(model, engine.check(scn, model, erp))]
    annotated: dict[int, list[Finding]] = {}
    for _ in range(MAX_FIX_ITERATIONS):  # each iteration fixes every failure and makes one revision (P2 R11)
        cur, findings = revs[-1]
        fails = [f for f in findings if f.status == "fail"]
        if not fails:
            break
        marked: dict[str, Finding] = {}
        for f in fails:
            live = {x.id: x for x in engine.check(scn, cur, erp)}.get(f.id)
            if live is None or live.status != "fail":
                continue
            cands = engine.fix_candidates(scn, cur, live, erp)
            if not cands:
                continue
            chosen, criterion, agent = choose_fix(live, cands)
            rejected = next((c for c in sorted(cands, key=lambda c: (c.cost_delta, c.id)) if c.id != chosen.id), None)
            cur = engine.apply_fix(cur, chosen)
            marked[f.id] = f.model_copy(update={
                "fix": {"candidate": chosen.id, "label": chosen.label, "criterion": criterion, "agent": agent,
                        "reason": f"{agent.capitalize()} chose this fix: {criterion}.",
                        "cost_delta": chosen.cost_delta, "deltas": dict(chosen.metrics)},
                "rejected_fix": None if rejected is None else {
                    "candidate": rejected.id, "label": rejected.label, "cost_delta": rejected.cost_delta,
                    "deltas": dict(rejected.metrics)}})
        annotated[len(revs) - 1] = [marked.get(x.id, x) for x in findings]
        revs.append((cur, engine.check(scn, cur, erp)))

    t0 = signed_at - 3600.0 * len(revs)
    revisions, by_rev = [], {}
    for i, (m, findings) in enumerate(revs):
        rid, counts = f"r{i + 1}", _counts(findings)
        status = "signed" if i == len(revs) - 1 and counts["fail"] == 0 else "checked"
        summary = (f"First pass of the {topology} design: {counts['fail']} failing checks." if i == 0
                   else f"After fixes: {counts['pass']} checks pass, {counts['fail']} fail.")
        revisions.append(Revision(id=rid, project_id=project.id, parent=f"r{i}" if i else None, author=AGENT_AUTHOR,
                                  hash=engine.model_hash(m), model=m, summary=summary, check_summary=counts,
                                  status=status, ledger=_ledger(engine, option.swaps), created_at=round(t0 + 3600.0 * i, 3)))
        by_rev[rid] = annotated.get(i, findings)
    signed = revisions[-1]
    if signed.status != "signed":
        raise ValueError(f"{project.id}: {topology} is not checker-clean after {MAX_FIX_ITERATIONS} fix iterations")
    approval = Approval(id=f"appr-{project.id}-1", revision=signed.id, approver_name=REVIEWER, role=REVIEWER_ROLE,
                        decision="approved", comment="Checked the fixes and the assumptions ledger. Approved for procurement.",
                        ts=round(signed_at, 3))
    final = revs[-1][0]
    prs = prs_by_vendor(engine.derive_pr_lines(scn, final, erp), erp, project_id=project.id, revision=signed.id,
                        created_at=signed_at + 120.0, pr_ids=pr_ids)
    crm = (CrmOverlay(opportunity_id=opportunity_id, stage="Design approved", updated_at=round(signed_at + 300.0, 3))
           if opportunity_id else None)
    wifs = chip_what_ifs(engine, scn, final, erp, f"seed:{project.id}@{signed.id}") if what_ifs else []
    return ProjectBundle(project=project.model_copy(update={"updated_at": round(signed_at + 300.0, 3)}),
                         revisions=revisions, findings=by_rev, approvals=[approval], prs=prs, crm=crm, what_ifs=wifs)


def asset_bundle(project: Project, pack: str, result: dict, at: float) -> ProjectBundle:
    """Ruling W18 (P3 R5, P2 R33): tool_call → tool_result {tool, summary + choice} → asset message (choice reason)."""
    tool = {"grid": "evaluate_grid", "solar": "evaluate_solar"}[pack]
    step = "asset.evaluate"
    start, end = round(at - 30.0, 3), round(at, 3)
    summary = jsonable(result)
    reason = f"{summary.get('recommended')} is the engine's recommended option and passes every asset-pack check."
    summary["choice"] = {"option": summary.get("recommended"), "reason": reason, "source": "engine"}
    events = [RunEvent(seq=1, phase="p1", step=step, attempt=1, agent="asset", kind="tool_call",
                       title=f"Asset agent ran {tool}", payload={"tool": tool, "args": {}}, ts=start),
              RunEvent(seq=2, phase="p1", step=step, attempt=1, agent="asset", kind="tool_result",
                       title=f"{tool} finished", payload={"tool": tool, "summary": summary}, ts=end),
              RunEvent(seq=3, phase="p1", step=step, attempt=1, agent="asset", kind="message", title=reason, ts=end)]
    steps = [StepRecord(id=step, phase="p1", status="done", attempt=1, started_at=start, finished_at=end)]
    return ProjectBundle(project=project.model_copy(update={"updated_at": end}), steps=steps, events=events)


def archive_bundle(project: Project, prs: list[PurchaseRequisition]) -> ProjectBundle:
    return ProjectBundle(project=project, prs=sorted(prs, key=lambda p: p.id))
```

```python
def _walk(value: Any, fn: Callable[[str], str]) -> Any:
    if isinstance(value, str):
        return fn(value)
    if isinstance(value, dict):
        return {fn(k): _walk(v, fn) for k, v in value.items()}
    if isinstance(value, list):
        return [_walk(v, fn) for v in value]
    return value

def check_golden(raw: RawCapture) -> None:
    b, problems = raw.bundle, []
    run = b.runs[0] if b.runs else None
    if run is None or run.project_id != "hall-b" or run.status != "done":
        problems.append("the run is not a finished Hall B run")
    approved = [a for a in b.approvals if a.decision == "approved"]
    if len(approved) != 1:
        problems.append(f"expected exactly one approval, found {len(approved)}")
    else:
        signed = next((r for r in b.revisions if r.id == approved[0].revision), None)
        if signed is None or signed.status != "signed":
            problems.append("the approved revision is not signed")
        elif signed.check_summary.get("fail", 0):
            problems.append("the signed revision still has failing checks")
    if len(b.revisions) < 2:
        problems.append("a golden run has a failing first revision and a fixed one")
    if not b.prs or any(p.status != "submitted" for p in b.prs):
        problems.append("PRs are missing or not all submitted")
    if b.crm is None or b.crm.stage != "Design approved":
        problems.append("the CRM overlay is missing or not 'Design approved'")
    if not b.events:
        problems.append("no committed events")
    if problems:
        raise CaptureError("; ".join(problems))


def export_run(store, blobs: BlobReader, uid: str, rid: str) -> RawCapture:
    ws, rp = f"workspaces/{uid}", f"workspaces/{uid}/runs/{rid}"
    run_doc = store.get_doc(rp)
    if run_doc is None:
        raise CaptureError(f"run {rid} not found in {ws}")
    run = _model(RunRecord, run_doc)
    steps = [_model(StepRecord, d) for d in store.list_docs(f"{rp}/steps")]
    done = {s.id: s.attempt for s in steps if s.status == "done"}
    events = [e for e in (_model(RunEvent, d) for d in store.list_docs(f"{rp}/events", order_by="seq"))
              if done.get(e.step) == e.attempt]  # only the attempt that committed each step (P2 R4)
    intake = _outputs(store, blobs, rp, "p1.intake") or {}
    docs = _outputs(store, blobs, rp, "p3.docs") or {}
    prefix = f"{rid}-r"
    revisions: list[Revision] = []
    findings: dict[str, list[Finding]] = {}
    for d in store.list_docs(f"{ws}/revisions"):
        if not str(d.get("id", "")).startswith(prefix):
            continue
        rev = _model(Revision, d)
        model = rev.model or DesignModel.model_validate_json(blobs.get(f"{ws}/{rev.model_url}"))
        revisions.append(rev.model_copy(update={"model": model, "model_url": None}))
        findings[rev.id] = [_model(Finding, f) for f in store.list_docs(f"{ws}/revisions/{rev.id}/findings")]
    revisions.sort(key=lambda r: int(r.id[len(prefix):]))
    ids = {r.id for r in revisions}
    crm_doc = store.get_doc(f"{ws}/crm/opp-hall-b")
    bundle = ProjectBundle(
        project=HALL_B.model_copy(update={"updated_at": run.finished_at or run.started_at}),
        brief=DesignBrief.model_validate(intake["brief"]) if intake.get("brief") else None,
        runs=[run], steps=[s for s in steps if s.status == "done"], events=events, revisions=revisions,
        findings=findings,
        approvals=[_model(Approval, d) for d in store.list_docs(f"{ws}/approvals") if d.get("revision") in ids],
        prs=[_model(PurchaseRequisition, d) for d in store.list_docs(f"{ws}/prs") if d.get("revision") in ids],
        crm=_model(CrmOverlay, crm_doc) if crm_doc else None)
    raw = RawCapture(rid=rid, bundle=bundle, docs_order=docs.get("order") or DOCS_ORDER,
                     docs_summary=docs.get("summary", ""))
    anonymous = RawCapture.model_validate(_walk(raw.model_dump(mode="json"), lambda s: s.replace(uid, "visitor")))
    check_golden(anonymous)
    return anonymous


def _times(b: ProjectBundle) -> list[float]:
    ts = [e.ts for e in b.events] + [a.ts for a in b.approvals] + [p.created_at for p in b.prs]
    ts += [r.created_at for r in b.revisions]
    for run in b.runs:
        ts += [run.started_at] + ([run.finished_at] if run.finished_at is not None else [])
    for s in b.steps:
        ts += [s.started_at] + ([s.finished_at] if s.finished_at is not None else [])
    if b.crm:
        ts.append(b.crm.updated_at)
    return ts


def time_map(times: list[float], anchor_from: float, anchor_to: float) -> Callable[[float], float]:
    """Monotone map: gaps longer than MAX_GAP_S (people waiting at gates) shrink to GAP_S; anchor_from → anchor_to."""
    pts = sorted(set(times) | {anchor_from})
    acc, out = 0.0, {}
    for i, t in enumerate(pts):
        if i:
            gap = t - pts[i - 1]
            acc += GAP_S if gap > MAX_GAP_S else gap
        out[t] = acc
    offset = anchor_to - out[anchor_from]

    def m(t: float) -> float:
        if t in out:
            return round(out[t] + offset, 3)
        base = pts[max(bisect.bisect_right(pts, t) - 1, 0)]
        return round(out[base] + min(max(t - base, 0.0), GAP_S) + offset, 3)

    return m


def to_static(raw: RawCapture, engine, scn, erp, *, target: CaptureTarget, signed_at: float) -> CapturedBundle:
    check_golden(raw)
    b, pid = raw.bundle, target.project.id
    prefix = f"{raw.rid}-r"
    rev_map = {r.id: f"r{r.id[len(prefix):]}" for r in b.revisions}
    pr_map = {p.id: f"PR-2026-{target.pr_base + i:04d}"
              for i, p in enumerate(sorted(b.prs, key=lambda p: (p.created_at, p.id)))}
    swaps = sorted({**rev_map, **pr_map, raw.rid: target.run_id}.items(), key=lambda kv: (-len(kv[0]), kv[0]))
    approval = next(a for a in b.approvals if a.decision == "approved")
    tmap = time_map(_times(b), approval.ts, signed_at)

    def text(s: str) -> str:
        for old, new in swaps:
            s = s.replace(old, new)
        s = re.sub(r"exports/r\d+/calc-report\.pdf", f"{target.files_url}/{CALC_REPORT}", s)
        s = re.sub(r"exports/r\d+/boq\.csv", f"{target.files_url}/{BOQ}", s)
        s = s.replace("workspaces/visitor/", f"seed/{pid}/")
        s = s.replace(HALL_B.name, target.project.name).replace("opp-hall-b", target.opportunity_id)
        s = s.replace("hall-b", pid).replace("Hall B", target.short_name)
        return s.replace(VISITOR_NAME, REVIEWER)

    models = {rev_map[r.id]: r.model for r in b.revisions}
    run_hash = {rev_map[r.id]: r.hash for r in b.revisions}
    data = b.model_dump(mode="json")
    for r in data["revisions"]:
        r["model"] = None  # models are never rewritten, so their hashes survive (P2 R22)
    out = ProjectBundle.model_validate(_walk(data, text))
    signed_rev = rev_map[approval.revision]

    revisions = []
    for r in out.revisions:
        h = engine.model_hash(models[r.id])
        if h != run_hash[r.id]:
            raise CaptureError(f"{r.id}: engine hash {h[:12]} differs from the run's {run_hash[r.id][:12]} (P2 R22)")
        revisions.append(r.model_copy(update={
            "project_id": pid, "model": models[r.id], "model_url": None, "hash": h, "created_at": tmap(r.created_at),
            "author": CAPTURED_AUTHOR if r.author == LIVE_AUTHOR else r.author,
            "status": "signed" if r.id == signed_rev else r.status}))
    r0 = out.runs[0]
    run = r0.model_copy(update={"id": target.run_id, "project_id": pid, "status": "done", "gate": None, "lease": None,
                                "started_at": tmap(r0.started_at),
                                "finished_at": tmap(r0.finished_at) if r0.finished_at is not None else None})
    steps = sorted((s.model_copy(update={"started_at": tmap(s.started_at),
                                         "finished_at": tmap(s.finished_at) if s.finished_at is not None else None})
                    for s in out.steps), key=lambda s: (s.started_at, s.id))
    events = [e.model_copy(update={"seq": i + 1, "ts": tmap(e.ts)})
              for i, e in enumerate(sorted(out.events, key=lambda e: e.seq))]
    approvals = [a.model_copy(update={"id": f"appr-{pid}-1", "approver_name": REVIEWER, "role": REVIEWER_ROLE,
                                      "ts": tmap(a.ts), "comment": a.comment or "Approved for procurement."})
                 for a in out.approvals if a.decision == "approved"]
    prs = sorted((p.model_copy(update={"project_id": pid, "status": "submitted", "created_at": tmap(p.created_at)})
                  for p in out.prs), key=lambda p: p.id)
    crm = out.crm.model_copy(update={"opportunity_id": target.opportunity_id, "updated_at": tmap(out.crm.updated_at)})
    what_ifs = chip_what_ifs(engine, scn, models[signed_rev], erp, f"seed:{pid}@{signed_rev}", required=True)
    last = max([e.ts for e in events] + [a.ts for a in approvals] + [p.created_at for p in prs] + [crm.updated_at])
    bundle = ProjectBundle(project=target.project.model_copy(update={"updated_at": last}),
                           brief=out.brief.model_copy(update={"project_id": pid}) if out.brief else None,
                           runs=[run], steps=steps, events=events, revisions=revisions, findings=out.findings,
                           approvals=approvals, prs=prs, crm=crm, what_ifs=what_ifs)
    _check_rewritten(bundle, raw.rid, signed_rev)
    return CapturedBundle(bundle=bundle, docs_order=list(raw.docs_order), docs_summary=text(raw.docs_summary))

class GcsReader:

        return self._bucket.blob(path).download_as_bytes()


def find_workspace_for_run(db, rid: str) -> str:
```

```python
"""Activity feed and notifications (spec §13.2–13.3): derived from the project bundles plus world.yaml's authored
background activity. Deterministic: bundle timestamps, or anchor offsets with seeded jitter."""
from kirchhoff.contracts import ProjectBundle

from .config import WorldConfig, rng_for


def tool_summary(b: ProjectBundle) -> dict:
    results = [e for e in b.events if e.kind == "tool_result"]
    return results[-1].payload.get("summary", {}) if results else {}


def _fails(b: ProjectBundle) -> list[str]:
    if not b.revisions:
        return []
    return [f"{f.rule_id} {f.element_id}" for f in b.findings.get(b.revisions[0].id, []) if f.status == "fail"]


def activity(cfg: WorldConfig, bundles: dict[str, ProjectBundle]) -> list[dict]:
    rng = rng_for(cfg, "activity")
    items = [(cfg.ts(a.days_ago) + rng.randint(0, 3600), a.actor, a.project_id, a.text) for a in cfg.activity]
    for pid, b in sorted(bundles.items()):
        name = cfg.project(pid).name
        if b.runs:
            items.append((b.runs[0].started_at, "Arjun Mehta", pid, f"started a design run on {name}"))
        if _fails(b):
            items.append((b.revisions[0].created_at, "Checker", pid,
                          f"flagged {', '.join(_fails(b))} on {b.revisions[0].id}"))
        for a in b.approvals:
            items.append((a.ts, a.approver_name, pid, f"approved and signed {a.revision} of {name}"))
        for p in b.prs:
            actor = "Procurement agent" if b.revisions else "Rohan Das"
            items.append((p.created_at, actor, pid, f"submitted {p.id} to the ERP sandbox ({len(p.lines)} lines)"))
        if b.crm:
            items.append((b.crm.updated_at, "Neha Kapoor", pid, f"moved {name} to {b.crm.stage} in the CRM"))
        if not b.revisions and tool_summary(b):
            items.append((b.events[-1].ts, "Asset agent", pid,
                          f"evaluated {name}; recommended {tool_summary(b).get('recommended')}"))
    items.sort(key=lambda x: (-x[0], x[3]))
    return [{"id": f"act-{i + 1:03d}", "ts": round(ts, 3), "actor": actor, "project_id": pid, "text": text}
            for i, (ts, actor, pid, text) in enumerate(items)]


def notifications(cfg: WorldConfig, bundles: dict[str, ProjectBundle]) -> list[dict]:
    items = []
    for pid, b in sorted(bundles.items()):
        name = cfg.project(pid).name
        if _fails(b):
            items.append({"ts": b.revisions[0].created_at, "kind": "finding",
                          "title": f"Checker flagged {len(_fails(b))} failures on {name} {b.revisions[0].id}",
                          "body": ", ".join(_fails(b)), "project_id": pid})
        for a in b.approvals:
            items.append({"ts": a.ts, "kind": "approval", "title": f"{name} {a.revision} approved by {a.approver_name}",
                          "body": f"{len(b.prs)} purchase requisitions submitted to the ERP sandbox", "project_id": pid})
        if not b.revisions and tool_summary(b):
            items.append({"ts": b.events[-1].ts, "kind": "check", "title": f"{name}: asset-pack evaluation complete",
                          "project_id": pid})
    items.sort(key=lambda n: (-n["ts"], n["title"]))
    return [{"id": f"n-{i + 1:02d}", **n, "ts": round(n["ts"], 3)} for i, n in enumerate(items)]
```

```python
"""Assemble the demo world (spec §13, obligations §3): world.json and integrations.json (P3 `World` /
`IntegrationsSnapshot`), project bundles, documents, the enterprise seed and a manifest. Deterministic (spec §16)."""
import hashlib
import json
from dataclasses import dataclass, field
from pathlib import Path

from kirchhoff.contracts import ProjectBundle

from ..capture import BOQ, CALC_REPORT, DOCS_ORDER, TARGETS, CapturedBundle, RawCapture, render_capture_docs, to_static
from .config import WorldConfig
from .docs import boq_csv_bytes, summary_pdf
from .enterprise_data import (MaterialsErp, build_enterprise_seed, build_historical_prs, build_materials,
                              hall_a_materials)
from .feed import activity, notifications, tool_summary
from .projects import archive_bundle, engine_bundles, project_record

DEMO = "apps/web/public/demo"
OUT = "scenarios/demo_world/out"
MANIFEST = f"{OUT}/manifest.json"
MANAGED_DIRS = (f"{DEMO}/projects", f"{DEMO}/files")
SCENARIO_DOCS = (("tender", "tender-hall-a.pdf"), ("drawing", "hall-a-plan.pdf"))  # WS3 copies them to /demo/docs


@dataclass
class WorldBuild:
    files: dict[str, bytes] = field(default_factory=dict)

    def manifest(self) -> dict[str, str]:
        return {rel: hashlib.sha256(data).hexdigest() for rel, data in sorted(self.files.items()) if rel != MANIFEST}

    def digest(self) -> str:
        return hashlib.sha256(json.dumps(self.manifest(), sort_keys=True).encode("utf-8")).hexdigest()


def _json_bytes(value) -> bytes:
    return (json.dumps(value, ensure_ascii=False, indent=2) + "\n").encode("utf-8")


def _asset_docs(cfg: WorldConfig, bundles: dict[str, ProjectBundle]) -> dict[str, dict[str, bytes]]:
    out: dict[str, dict[str, bytes]] = {}
    for pid in ("grid-132kv", "solar-5mwp"):
        s = tool_summary(bundles[pid]) if pid in bundles else {}
        if not s:
            continue
        rows = [("Recommended option", str(s.get("recommended"))),
                ("Options compared", ", ".join(str(o.get("id")) for o in s.get("options", []))),
                ("Findings", "; ".join(f"{f.get('rule_id')} {f.get('element_id')}: {f.get('status')}"
                                       for f in s.get("findings", [])) or "none")]
        out[pid] = {"summary.pdf": summary_pdf(cfg.project(pid).name, "Asset-pack evaluation", rows)}
    vindhya = bundles.get("vindhya-lv")
    if vindhya is not None and vindhya.prs:
        out["vindhya-lv"] = {BOQ: boq_csv_bytes([line for p in vindhya.prs for line in p.lines])}
    return out


def _documents(cfg: WorldConfig, bundles: dict[str, ProjectBundle], files_docs: dict[str, dict[str, bytes]],
               scenarios_root: Path) -> list[dict]:
    def updated(pid: str) -> float:
        return bundles[pid].project.updated_at if pid in bundles else cfg.ts(cfg.project(pid).days_ago)

    rows = [(pid, kind, name, f"/demo/docs/{name}") for pid in ("hall-a", "hall-b") for kind, name in SCENARIO_DOCS
            if (scenarios_root / "hall_a" / "out" / name).exists()]
    for pid in sorted(files_docs):
        for name in sorted(files_docs[pid]):
            kind = "boq" if name == BOQ else "calc_report" if name == CALC_REPORT else "summary"
            rows.append((pid, kind, name, f"/demo/files/{pid}/{name}"))
    return [{"id": f"doc-{pid}-{name.rsplit('.', 1)[0]}", "project_id": pid, "name": name, "kind": kind, "url": url,
             "updated_at": updated(pid)} for pid, kind, name, url in rows]


def build_world(cfg: WorldConfig, *, scenarios_root: Path, engine=None, captures: dict[str, RawCapture] | None = None,
                engine_projects: bool = True) -> WorldBuild:
    scenarios_root = Path(scenarios_root)
    captures = dict(captures or {})
    if set(captures) - set(TARGETS):
        raise ValueError(f"no capture target for {sorted(set(captures) - set(TARGETS))}")
    if captures and engine is None:
        raise ValueError("captures need the engine (hashes, chip what-ifs, BOQ)")
    materials = build_materials(cfg, hall_a_materials(scenarios_root))
    erp = MaterialsErp(materials)
    historical = build_historical_prs(cfg, materials)
    if engine is not None and engine_projects:
        bundles = engine_bundles(cfg, engine, scenarios_root, erp, historical)
    else:
        bundles = {"vindhya-lv": archive_bundle(project_record(cfg, "vindhya-lv"),
                                                [p for p in historical if p.project_id == "vindhya-lv"])}
    scn = engine.load_scenario("hall_a", scenarios_root) if engine is not None else None
    files_docs: dict[str, dict[str, bytes]] = {}
    for pid, raw in sorted(captures.items()):
        cap = to_static(raw, engine, scn, erp, target=TARGETS[pid],
                        signed_at=cfg.ts(cfg.project(pid).days_ago) - 300.0)
        bundles[pid] = cap.bundle
        files_docs[pid] = render_capture_docs(cap, engine, scn, erp)
    for pid in ("hall-a", "pune-edge-1"):  # engine-built fallbacks
        if pid in bundles and pid not in files_docs:
            b = bundles[pid]
            files_docs[pid] = render_capture_docs(CapturedBundle(bundle=b, docs_order=DOCS_ORDER,
                                                                 docs_summary=b.revisions[-1].summary), engine, scn, erp)
    files_docs.update(_asset_docs(cfg, bundles))
    seed = build_enterprise_seed(cfg, materials,
                                 [p for pid in ("hall-a", "pune-edge-1") if pid in bundles for p in bundles[pid].prs])
    world = {"org": cfg.org.model_dump(exclude_none=True),
             "people": [p.model_dump(exclude_none=True) for p in cfg.people],
             "projects": [(bundles[p.id].project if p.id in bundles else project_record(cfg, p.id)).model_dump(mode="json")
                          for p in cfg.projects],
             "activity": activity(cfg, bundles)}
    integrations = {"synced_at": cfg.now,
                    "erp": {"materials": [m.model_dump(mode="json") for m in seed.materials],
                            "prs": [p.model_dump(mode="json")
                                    for p in sorted(seed.prs, key=lambda p: (-p.created_at, p.id))]},
                    "crm": {"opportunities": [o.model_dump(mode="json") for o in seed.opportunities]},
                    "documents": _documents(cfg, bundles, files_docs, scenarios_root),
                    "notifications": notifications(cfg, bundles)}
    files = {f"{DEMO}/world.json": _json_bytes(world), f"{DEMO}/integrations.json": _json_bytes(integrations),
             f"{OUT}/enterprise_seed.json": (seed.model_dump_json(indent=1) + "\n").encode("utf-8")}
    for pid, bundle in sorted(bundles.items()):
        files[f"{DEMO}/projects/{pid}.json"] = (bundle.model_dump_json() + "\n").encode("utf-8")
    for pid, docs in sorted(files_docs.items()):
        for name, data in sorted(docs.items()):
            files[f"{DEMO}/files/{pid}/{name}"] = data
    build = WorldBuild(files)
    build.files[MANIFEST] = _json_bytes({"digest": build.digest(), "files": build.manifest()})
    return build


def write_world(build: WorldBuild, root: Path) -> list[str]:
    root = Path(root)
    for d in MANAGED_DIRS:
        folder = root / d
        if folder.is_dir():
            for f in sorted(folder.rglob("*")):
                if f.is_file() and f.relative_to(root).as_posix() not in build.files:
                    f.unlink()
    for rel, data in sorted(build.files.items()):
        path = root / rel
        path.parent.mkdir(parents=True, exist_ok=True)
        path.write_bytes(data)
    return sorted(build.files)


def diff_on_disk(build: WorldBuild, root: Path) -> list[str]:
    root = Path(root)
    return [rel for rel, data in sorted(build.files.items())
            if not (root / rel).exists() or (root / rel).read_bytes() != data]
```

```python
"""Build the demo world (spec §13): world.json, integrations.json, project bundles, documents, enterprise seed.
Deterministic (fixed seed and anchor). Run from services/api:
  uv run python ../../scenarios/demo_world/build.py            # write the files
  uv run python ../../scenarios/demo_world/build.py --check    # exit 1 if the committed files are stale
Captured runs in captures/{hall-a,pune-edge-1}.json (Task 14) take precedence over the engine-built bundles."""
import argparse
import importlib
import sys
from pathlib import Path

from kirchhoff.enterprise.capture import TARGETS, RawCapture
from kirchhoff.enterprise.world.build import build_world, diff_on_disk, write_world
from kirchhoff.enterprise.world.config import load_world_config

HERE = Path(__file__).resolve().parent
ROOT = HERE.parent.parent


def main(argv: list[str] | None = None) -> int:
    ap = argparse.ArgumentParser(description="Build the Kirchhoff demo world")
    ap.add_argument("--check", action="store_true", help="fail if the files on disk differ from a fresh build")
    args = ap.parse_args(argv)
    cfg = load_world_config(HERE / "world.yaml")
    try:
        engine = importlib.import_module("kirchhoff.engine.api")
    except ImportError:
        engine = None
        print("build: kirchhoff.engine.api is missing; building without engine projects", file=sys.stderr)
    captures = {pid: RawCapture.model_validate_json((HERE / "captures" / f"{pid}.json").read_text(encoding="utf-8"))
                for pid in sorted(TARGETS) if (HERE / "captures" / f"{pid}.json").exists()}
    if captures and engine is None:
        print("build: the captures need the engine", file=sys.stderr)
        return 1
    build = build_world(cfg, scenarios_root=ROOT / "scenarios", engine=engine, captures=captures)
    if build_world(cfg, scenarios_root=ROOT / "scenarios", engine=engine, captures=captures).digest() != build.digest():
        print("build: two builds differ; the generator is not deterministic", file=sys.stderr)
        return 1
    if args.check:
        stale = diff_on_disk(build, ROOT)
        if stale:
            print("stale demo-world files: " + ", ".join(stale), file=sys.stderr)
            return 1
        print(f"demo world up to date ({build.digest()[:16]})")
        return 0
    written = write_world(build, ROOT)
    bundles = sorted(r.rsplit("/", 1)[1] for r in written if "/projects/" in r)
    print(f"demo world {build.digest()[:16]}: {len(written)} files; bundles {bundles}; captured {sorted(captures)}")
    return 0


if __name__ == "__main__":
    sys.exit(main())
```

```bash
#!/usr/bin/env bash
# Firebase App Check (spec §1, §7; rulings W13, W19). Usage:
#   infra/appcheck.sh debug-token          create or reuse the Playwright debug token (Secret Manager) and register it
#   infra/appcheck.sh status               enforcement mode of Firestore, Cloud Storage and Firebase AI Logic
#   infra/appcheck.sh enforce|unenforce    switch all three
set -euo pipefail
P=ordinal-mep
APP_ID="1:1015632998221:web:c98110f2fc88424da81104"
SECRET=kirchhoff-e2e-appcheck-debug-token
API="https://firebaseappcheck.googleapis.com/v1/projects/$P"
SERVICES=(firestore.googleapis.com firebasestorage.googleapis.com firebaseml.googleapis.com)

call() {  # method url [json body]
  local body="${3:-}"
  if [ -n "$body" ]; then
    curl -fsS -X "$1" -H "Authorization: Bearer $(gcloud auth print-access-token)" -H "x-goog-user-project: $P" \
      -H "Content-Type: application/json" "$2" -d "$body"
  else
    curl -fsS -X "$1" -H "Authorization: Bearer $(gcloud auth print-access-token)" -H "x-goog-user-project: $P" "$2"
  fi
}

case "${1:-}" in
  debug-token)
    gcloud services enable secretmanager.googleapis.com firebaseappcheck.googleapis.com --project=$P
    if ! gcloud secrets describe $SECRET --project=$P >/dev/null 2>&1; then
      python3 -c 'import uuid; print(uuid.uuid4(), end="")' \
        | gcloud secrets create $SECRET --project=$P --replication-policy=automatic --data-file=-
    fi
    VALUE="$(gcloud secrets versions access latest --secret=$SECRET --project=$P)"
    REGISTERED="$(call GET "$API/apps/$APP_ID/debugTokens" | python3 -c 'import json, sys
print(any(t.get("displayName") == "playwright-e2e" for t in json.load(sys.stdin).get("debugTokens", [])))')"
    if [ "$REGISTERED" = "True" ]; then
      echo "debug token playwright-e2e already registered"
    else
      call POST "$API/apps/$APP_ID/debugTokens" "{\"displayName\": \"playwright-e2e\", \"token\": \"$VALUE\"}" >/dev/null
      echo "debug token playwright-e2e registered (value only in Secret Manager: $SECRET)"
    fi
    ;;
  status)
    for s in "${SERVICES[@]}"; do
      printf '%s ' "$s"
      call GET "$API/services/$s" | python3 -c 'import json, sys; print(json.load(sys.stdin).get("enforcementMode", "OFF"))'
    done
    ;;
  enforce|unenforce)
    MODE=UNENFORCED
    if [ "$1" = enforce ]; then MODE=ENFORCED; fi
    for s in "${SERVICES[@]}"; do
      call PATCH "$API/services/$s?updateMask=enforcementMode" "{\"enforcementMode\": \"$MODE\"}" >/dev/null
    done
    "$0" status
    ;;
  *)
    echo "usage: $0 debug-token|status|enforce|unenforce" >&2
    exit 2
    ;;
esac
```

````markdown
## Changing anything after the freeze (Thu 16 Oct 22:00 IST)
- Commit, then `make release TAG=<name>` (`infra/release.sh`); it runs every test, `build.py --check`, deploys, runs e2e and tags. Never `FORCE=1`.
- `infra/deploy_api.sh` refuses while `infra/live_runs.py` sees a live lease (a visitor's run heartbeat < 60 s old): wait and retry.
- If the golden path changes, recapture (plan Task 14), then release.
````
